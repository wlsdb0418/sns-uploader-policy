1. 목적과 제공 범위

이 약관은 저혈압특공대 SNS 영상 스튜디오를 이용한 로컬 영상 관리, 변환, 승인 및 SNS 전송 예약에 적용됩니다. 프로그램은 독립적인 도구이며 TikTok, Meta 또는 Google이 운영하거나 보증하는 서비스가 아닙니다.

2. 계정 연결과 게시 승인

사용자는 본인이 관리 권한을 가진 SNS 계정만 연결해야 합니다. 기본 모의 업로드는 실제 게시를 하지 않습니다. 실제 전송은 현재 버전의 영상과 문구를 최종 승인하고 대상 계정과 서비스별 전송 동작을 확인한 경우에 수행합니다. 계정 연결 자체는 게시 승인이 아닙니다.

YouTube 전송은 비공개 업로드, Instagram 전송은 공개 릴스 게시입니다. TikTok은 받은편지함 전송만 지원하며 제목·공개 범위 선택과 최종 게시는 TikTok 앱에서 사용자가 완료합니다.

3. 사용자 책임

사용자는 영상, 음원, 이미지 및 문구의 저작권·초상권 등 필요한 권리를 확보하고 각 SNS의 약관과 정책을 준수해야 합니다. 타인의 계정·인증 정보를 무단으로 이용하거나 불법 콘텐츠를 전송해서는 안 됩니다. 게시 전 내용과 대상 계정을 확인하고 인증 정보를 안전하게 보관해야 합니다.

4. 운영 조건과 제한

예약 처리는 PC와 프로그램이 실행 중이고 인터넷에 연결되어 있을 때 이루어집니다. 앱 권한, 심사, 전송 한도, 계정 제한, 네트워크 및 외부 API 변경으로 전송이 지연되거나 실패할 수 있습니다. 특정 시각의 게시나 플랫폼 심사 통과를 보장하지 않습니다.

중복 예약을 제한하고 결과가 불명확한 전송은 자동 반복하지 않도록 처리하지만, 새 프로젝트로 같은 파일을 가져오는 경우까지 중복을 판별하지는 않습니다. 사용자는 원격 결과가 불명확할 때 해당 SNS에서 기존 게시물을 확인해야 합니다.

5. 비용과 이용 종료

현재 프로그램에는 결제 기능이 없습니다. 사용자 인터넷·저장 장치 및 별도로 이용하는 외부 서비스의 비용은 해당 제공자의 조건에 따릅니다. 사용자는 프로그램을 종료하고 예약을 취소하거나 연결을 해제할 수 있습니다. 로컬 연결 해제만으로 외부 서비스의 권한이나 게시물이 삭제되지는 않습니다.

6. 개인정보와 변경

데이터 처리와 삭제 방법은 개인정보처리방침에 설명합니다. 기능이나 데이터 처리에 중요한 변경이 있는 경우 업데이트 문서와 정책 페이지에 알립니다. 이 약관은 적용 법령에 따른 이용자의 권리를 제한하지 않습니다.
