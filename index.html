저혈압특공대 SNS 영상 스튜디오

완성된 영상을 Windows PC에서 관리하고, 사용자가 내용을 확인·승인한 뒤 SNS 전송을 예약하는 로컬 프로그램입니다.

서비스별 기능

  • YouTube: 연결한 계정에 비공개 영상 업로드.
  • Instagram: 필요한 계정·앱 권한이 있는 경우 공개 릴스 게시.
  • TikTok: 받은편지함으로 영상을 전송하며, 최종 게시는 사용자가 TikTok 앱에서 완료합니다.

기본 모드는 모의 업로드입니다. 실제 전송에는 서비스별 계정 연결과 별도의 확인이 필요합니다. Instagram·TikTok 실계정 검증은 진행 전이며 개발자 권한과 앱 심사 상태에 따라 사용이 제한될 수 있습니다. TikTok Direct Post는 제공하지 않습니다.

이 웹사이트는 프로그램 안내와 정책 문서를 제공합니다. 영상 업로드나 SNS 로그인은 이 사이트에서 수행하지 않습니다.
