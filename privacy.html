개인정보처리방침

시행일: 2026년 10월 26일

1. 프로그램과 데이터 처리 위치

저혈압특공대 SNS 영상 스튜디오는 사용자의 Windows PC에서 실행되는 로컬 프로그램입니다. 운영자에게 영상이나 인증 정보를 모으는 중앙 서버를 제공하지 않습니다. 이 안내 웹사이트에는 영상 업로드, 로그인, 분석 스크립트 또는 광고 기능이 없습니다.

2. 처리하는 정보와 목적

  • 사용자가 선택한 영상과 제목·설명: 변환, 미리보기, 승인 및 SNS 전송.
  • 연결된 SNS 계정 ID와 표시 이름: 게시 대상 확인 및 예약 계정 일치 확인.
  • 사용자가 등록하거나 승인한 앱 인증 정보, 액세스 토큰 및 선택적 갱신 토큰: 계정 조회와 허용한 전송 요청.
  • 승인 버전, 예약 시각, 전송 상태, 원격 작업 ID와 세션 정보: 예약 처리, 오류 복구 및 중복 전송 방지.

3. 저장과 보안

기본 저장 위치는 Windows의 %LOCALAPPDATA%\SNS-Auto-Uploader입니다. 별도로 저장 경로를 지정했다면 해당 경로를 사용합니다. 인증 정보는 Windows 현재 사용자 DPAPI로 암호화하며, 영상과 로컬 데이터베이스는 별도 암호화 없이 저장됩니다. 데이터베이스에는 복구용 업로드 세션 정보가 포함될 수 있습니다. 사용자는 PC 접근과 백업 파일을 보호해야 합니다.

사용자가 등록한 원본 JSON 인증 파일은 프로그램 외부에 그대로 남을 수 있습니다. 공유 폴더에 두지 말고 필요가 없으면 직접 삭제하세요.

4. 외부 서비스 전송

계정 확인 시 해당 서비스에 인증 정보와 계정 조회 요청을 보냅니다. 사용자가 승인하고 실제 전송을 예약하면 연결된 서비스에 영상과 필요한 정보가 전송됩니다. Instagram·YouTube에는 설정한 문구가 포함됩니다. TikTok 받은편지함 전송 API에는 프로그램의 제목·설명을 보내지 않으며, 사용자가 앱에서 작성합니다.

외부 서비스의 데이터 처리·보관·국외 처리에는 각 제공자의 정책이 적용됩니다: TikTok, Instagram / Meta, Google / YouTube. 웹페이지 호스팅 제공자는 접속 IP와 기본 요청 기록 등을 자체 정책에 따라 처리할 수 있습니다.

5. 보관 기간과 삭제

로컬 데이터는 사용자가 삭제할 때까지 보관하며, 자동 정리 기능은 아직 없습니다. 임시 원본 영상은 변환 작업 후 정리되지만 변환 영상·프로젝트·전송 이력은 남습니다. 계정 연결 해제는 이 PC에 저장된 해당 서비스 인증 정보를 삭제합니다.

전체 데이터를 삭제하려면 먼저 대기 예약과 원격 전송 상태를 확인한 뒤 프로그램을 종료하고 위 데이터 폴더와 불필요한 백업·입력 JSON 파일을 삭제하세요. 이 작업은 되돌릴 수 없으므로 보관할 영상은 먼저 별도로 저장하세요. SNS에서 이미 전송·게시된 영상은 해당 SNS에서 별도로 삭제해야 합니다.

6. 권한 철회와 문의

프로그램에서 계정 연결을 해제하고, 해당 SNS 계정의 연결된 앱·권한 관리 화면에서 접근 권한을 철회할 수 있습니다. 운영자는 사용자의 로컬 파일에 원격 접근할 수 없으므로 로컬 자료의 열람·수정·삭제는 사용자 PC에서 수행합니다. 프로그램 제공자와의 기존 연락 경로를 통해 문의할 때 토큰·비밀번호·인증 코드를 보내지 마세요.

7. 변경 안내

데이터 처리 방식이 바뀌면 이 페이지의 시행일과 내용을 갱신하고 프로그램 업데이트 문서에 안내합니다.
